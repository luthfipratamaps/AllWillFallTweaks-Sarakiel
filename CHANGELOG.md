# Changelog

## 0.10.1 — Weather direct hooks (experimental)
- Added native sea-level Raise/Lower buttons with one-time method detection and fail-closed behavior.
- Added independent getter patches for rain intensity, wind, extra physics stress, sea flow, and cloudiness.
- Weather presets now adjust effective weather parameters (not forecast blocks/sky profiles).
- Preserved prior resource, capacity, construction, research, production, and citizen hooks.
- Changed sea step labels to **native units** because the game's unit-to-meter scale is unverified.

## 0.10.0 — Weather discovery
- Added Weather tab and one-time weather API probe; no gameplay changes.
